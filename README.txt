FENCING ANALYTICS V4 — FIE PDF IMPORT

Що додано:
- Окремий імпорт FIE з трьох PDF: Pools, Tableau, Results.
- Pool Results не потрібен.
- Чинний імпорт Fencing Time Live JSON залишено окремим і без змін.
- PDF обробляються локально у браузері через PDF.js; для завантаження бібліотеки потрібен інтернет.
- Після імпорту дані можна перевірити, завантажити нормалізований JSON або зберегти у Supabase через звичний механізм програми.

Як спробувати локально:
1. Розпакуй архів.
2. Відкрий index.html у сучасному Chrome або Edge.
3. Перейди до «Імпорт змагання».
4. У блоці «Імпорт з FIE — PDF» вибери три PDF одного змагання: Pools, Tableau та Results.
5. Натисни «Перевірити та імпортувати FIE PDF».
6. Перевір звіт імпорту, вкладки «Спортсмени» та «Бої».

Для повноцінного збереження в Supabase та синхронізації краще розмістити файли на GitHub Pages, оскільки локальний file:// режим може мати обмеження авторизації/мережевих запитів.

Перевірка на тестовому комплекті FIE (Gand, 12.09.2026):
- 94 спортсмени у Pools + 1 окремий запис Results з місцем 9999.
- 14 груп.
- 270 групових боїв.
- 66 боїв DE: A128=3, A64=32, A32=16, A16=8, A8=4, A4=2, A2=1.
- Переможець фіналу за Tableau: BLOIN Maxence (15:10 проти ZAHREBELNIY Dmytrii).

Примітка:
- Pool Results є необов'язковим і не потрібен для цього імпорту.
- Імпорт не вигадує бої для спортсмена з місцем 9999, якщо його немає в групових протоколах.
